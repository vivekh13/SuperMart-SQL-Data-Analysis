# 🛒 SuperMart SQL Data Analysis

## 📌 Project Overview

This project is a SQL-based analysis of a fictional e-commerce database called **SuperMart**.

I created this project to practice SQL concepts on a structured relational database and gradually move from basic queries to more advanced SQL operations.

The database contains information about customers, employees, products, orders and order items.

---

## 🗂️ Database Structure

The project contains five main tables:

* `customers` – customer details and location
* `employees` – employee and manager information
* `products` – product details, categories, prices and stock
* `orders` – customer orders, dates, status and region
* `order_items` – products purchased in each order, quantity, price and discount

These tables are connected using primary and foreign keys.

## 📊 Analysis Performed

Some of the questions explored in this project include:

* Finding products by category and price
* Analyzing orders by region
* Calculating average product prices
* Finding customers with multiple orders
* Identifying customers who never placed an order
* Calculating product-wise revenue
* Ranking products within each category
* Calculating running revenue totals
* Finding high-value orders using CTEs
* Analyzing employee order handling
* Finding the top-selling product in each region

## 📁 Project Files

Contains the database structure and sample data required to run the project.

### `analysis_queries.sql`

Contains SQL queries from basic to advanced level used to analyze the SuperMart database.

---

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open your SQL environment.
3. Run `database_setup.sql` first to create and populate the tables.
4. Run `analysis_queries.sql` to execute the analysis queries.
